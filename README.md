# Многопользовательский чат с интеграцией поиска фильмов

Сетевое программирование — основа любого современного приложения: от мессенджеров до облачных сервисов. В этом проекте
вы создадите собственный **TCP-чат**, в котором пользователи могут обмениваться сообщениями в реальном времени. Но это
не просто чат: он умеет **искать фильмы в базе IMDB** по запросу и возвращать информацию в структурированном виде. Вы
примените всё, что изучили: сокеты, потоки ввода-вывода, обработку исключений, сериализацию в JSON и работу с внешними
HTTP-API. Это задание объединяет низкоуровневые навыки (сокеты) и высокоуровневые (интеграция с веб-сервисами), что
делает его отличной подготовкой к реальной разработке.

## **Описание Задачи**

Реализуйте клиент-серверное приложение «Чат», в котором:

- сервер принимает подключения от нескольких клиентов;
- клиенты могут отправлять текстовые сообщения всем участникам;
- любой клиент может выполнить команду `/movie <название>`, чтобы получить информацию о фильме из публичного API.

* **Основная функциональность**
    * **Сервер (`ChatServer`)**:
        - Запускается на заданном порту (например, `8080`).
        - Принимает подключения через `ServerSocket`.
        - Для каждого клиента создаёт отдельный поток обработки.
        - Рассылает все входящие сообщения всем подключённым клиентам.
        - Поддерживает список активных клиентов (можно отображать количество).
    * **Клиент (`ChatClient`)**:
        - Подключается к серверу по `host:port`.
        - Запрашивает имя пользователя при старте.
        - В отдельных потоках:
            - читает ввод от пользователя (через `Scanner`);
            - получает сообщения от сервера и выводит их в консоль.
        - Поддерживает команду:  
          `/movie <название фильма>` → отправляет запрос на сервер.
    * **Интеграция с IMDB**:
        - Сервер перехватывает команду `/movie ...`.
        - Выполняет HTTP-запрос к публичному API (например, [OMDb API](https://www.omdbapi.com/) — бесплатный, требует
          API-ключ).
        - Парсит JSON-ответ.
        - Отправляет клиенту структурированное сообщение:  
          `🎬 Найден фильм: "<название>" (год). Жанр: <жанр>. Рейтинг: <рейтинг>.`
        - Если фильм не найден — отправляет: `❌ Фильм не найден.`

* **Дополнительные условия / Ограничения**
    * Используйте только стандартную библиотеку Java + **одну** библиотеку для JSON (например, `org.json` или `Gson` —
      укажите в `pom.xml`/`build.gradle`).
    * Для HTTP-запросов к IMDB можно использовать `java.net.http.HttpClient` (Java 11+).
    * Все сетевые операции должны быть обёрнуты в `try-catch` с корректной обработкой `IOException`.
    * При отключении клиента — удаляйте его из списка и не пытайтесь отправлять ему сообщения.
    * Сообщения должны передаваться в формате UTF-8.
    * Имя пользователя должно отображаться в сообщениях: `[Иван]: Привет!`

* **Примеры использования**
    * **Пример сценария:**
        1. Студент запускает `ChatServer` на `localhost:8080`.
        2. Запускает два экземпляра `ChatClient`.
        3. Клиент 1 вводит: `Привет, всем!`
        4. Клиент 2 видит: `[Клиент1]: Привет, всем!`
        5. Клиент 2 вводит: `/movie Inception`
        6. Оба клиента получают:  
           `🎬 Найден фильм: "Inception" (2010). Жанр: Action, Sci-Fi. Рейтинг: 8.8.`

## Входные / Выходные данные (если применимо)

* **Вход (клиент):**
    - Текстовые сообщения
    - Команды вида `/movie <запрос>`

* **Выход (клиент):**
    - Сообщения от других пользователей: `[Имя]: <текст>`
    - Результаты поиска фильмов в формате выше

* **Формат обмена между клиентом и сервером:**  
  Простой текст в UTF-8 (без шифрования).  
  Команды начинаются с `/`.

* **Пример сообщения от сервера:**
  ```
  [Анна]: Какой сегодня фильм посмотрим?
  /movie The Matrix
  🎬 Найден фильм: "The Matrix" (1999). Жанр: Action, Sci-Fi. Рейтинг: 8.7.
  ```

## Технические требования

* Используйте `ServerSocket` и `Socket` для TCP-соединений.
* Для чтения/записи — `BufferedReader` / `BufferedWriter` с `InputStreamReader` / `OutputStreamWriter` в UTF-8.
* Сервер должен поддерживать **многопользовательский режим** (минимум 3 клиента одновременно).
* Для работы с JSON — выберите одну библиотеку и укажите её в зависимостях.
* Для HTTP-запросов — `java.net.http.HttpClient`.
* **Среда выполнения:** Консоль.

> 💡 **Совет по IMDB**: зарегистрируйтесь на [OMDb API](https://www.omdbapi.com/apikey.aspx) — ключ бесплатный и приходит
> мгновенно. Пример запроса:  
> `https://www.omdbapi.com/?t=Inception&apikey=ВАШ_КЛЮЧ`

## **Бонусные Задания (Необязательно)**

* **Личные сообщения**
    * Реализуйте команду `/msg <имя> <текст>` для отправки приватного сообщения.

* **История сообщений**
    * Сервер сохраняет последние 50 сообщений и отправляет их новому клиенту при подключении.

* **Поддержка UDP для уведомлений**
    * Реализуйте отдельный UDP-сервер, который рассылает широковещательное уведомление: `📢 Новый пользователь в чате!`,
      когда кто-то подключается.

* **Цветной вывод в консоли**
    * Используйте ANSI-коды для цветного отображения имён, команд и фильмов (например, имя — синим, фильмы — жёлтым).

* **Валидация имени пользователя**
    * Запретите использовать символы `/`, `:`, пробелы в начале/конце имени.
